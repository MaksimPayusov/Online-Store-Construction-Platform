# Платформа-конструктор интернет-магазинов
## Стек технологий
### Backend:
- Java 21,
- Java Spring,
- Gradle.
### Инфраструктура:
- PostgreSQL,
- Docker,
- Redis,
- RabbitMQ,
- Grafana,
- Prometheus,
- Keycloak,
- Krakend,
- MinIO.
### Административный frontend:
- React,
- TypeScript,
- Vite,
- Redux Toolkit.
### Клиентский frontend:
- React,
- Next.js,
- TypeScript.
