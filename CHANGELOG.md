# Changelog

Этот файл содержит выдуманные изменения по микросервисам.

## v1.7.0 (Январь)

### `cartservice`
- Добавлены правила объединения позиций с одинаковыми опциями.
- Пересмотрена логика применения скидок при частичной оплате.
- Исправлен баг с удалением последней позиции из корзины.

### `fileservice`
- Появился список последних загрузок для админов.
- Улучшено кэширование метаданных файлов.
- Исправлено создание превью для нестандартных форматов.

### `newsservice`
- Добавлены закрепленные новости.
- Появилось поле «источник» для внешних новостей.
- Исправлен вывод ленты при пустом запросе.

### `orderservice`
- Добавлена автогенерация номера заказа по шаблону.
- Внедрена проверка минимального количества товаров.
- Исправлены статусы при отмене в процессе доставки.

### `productservice`
- Добавлены метки “новинка/хит/скидка”.
- Улучшена фильтрация по диапазону цен.
- Исправлена загрузка изображений в связке с `fileservice`.

### `shop`
- Добавлены настройки времени работы по дням недели.
- Улучшена обработка карточек бренда.
- Исправлена выдача магазинов без витрины.

### `userservice`
- Добавлено подтверждение email при смене пароля.
- Улучшена защита от повторной регистрации.
- Исправлена синхронизация ролей при обновлении профиля.

## v1.6.0 (Декабрь)

### `cartservice`
- Добавлен пересчет итоговой стоимости с учетом промокодов и округления.
- В корзине появилась валидация наличия товара по складам.
- Оптимизированы запросы к БД при массовом обновлении позиций.

### `fileservice`
- Введено ограничение на размер загрузки по MIME-типу.
- Добавлен механизм временных ссылок с TTL.
- Улучшено логирование ошибок при загрузке файлов.

### `newsservice`
- Добавлена поддержка черновиков новостей.
- Появилась сортировка по дате публикации и приоритету.
- Исправлена выдача тегов при фильтрации.

### `orderservice`
- Внедрен расчет стоимости доставки отдельной позицией.
- Добавлена проверка адреса доставки на пустые поля.
- Ускорена агрегация истории заказов.

### `productservice`
- Добавлены вариации размеров с отдельными остатками.
- Реализована массовая смена статусов товаров.
- Исправлены ошибки округления цен в валютных конвертациях.

### `shop`
- Добавлена настройка минимальной суммы заказа на магазин.
- Улучшена валидация полей для витрины.
- Обновлены стандартные значения настроек доставки.

### `userservice`
- Расширены роли для модераторов контента.
- Реализована блокировка пользователя по причине.
- Улучшена обработка токенов при истечении сессии.
